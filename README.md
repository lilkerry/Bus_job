# 🚌 Realistic Bus Job - FiveM Script

A complete, production-ready bus driving job script for FiveM using QBX/QBCore framework. Drive passengers through Los Santos while managing realistic features like fuel consumption, traffic violations, and passenger boarding.

## ✨ Features
             KERRYGAMER
### 🚐 Core Features
- **4 Pre-configured Routes** - Downtown, Beach, Airport, Suburban
- **Multiple Stops** - Each route has 5-8 passenger pickup/dropoff locations
- **Realistic Mechanics**:
  - Fuel consumption system
  - Vehicle damage tracking
  - Speed limit enforcement
  - Passenger boarding animations
  - Bus door mechanics
  - Engine health checking

### 💰 Income System
- Base pay per route
- Per-passenger earnings ($25-$40)
- Distance-based bonuses
- On-time completion bonus (+$100)
- Perfect route bonus (+$200)
- Tax system (15% by default)
- Damage penalties

### 🎮 Gameplay Features
- GPS navigation with route blips
- Real-time HUD with earnings tracking
- Speeding ticket system with penalties
- Passenger count tracking
- Progress bar for stops
- Visual & audio feedback
- Professional notifications

### 🛠️ Configuration
- Fully customizable routes (add/edit stops)
- Adjustable payments and bonuses
- Traffic rule settings
- Damage thresholds
- Fuel consumption rates
- HUD positioning and visibility
- Localization support
